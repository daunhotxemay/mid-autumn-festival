# Đêm Hội Trăng Rằm - Yamaha Town Nam Tiến 🌕🥮

Landing page sự kiện Đêm Hội Trăng Rằm dành riêng cho khách hàng của hệ thống xe máy **Yamaha Town Nam Tiến** và **Nam Tiến Motor**.

## ✨ Tính năng nổi bật
- **Visual & Choreography 60fps**: Chuỗi animation xuất hiện tầng lớp với hiệu ứng mượt mà (GSAP 3 & ScrollTrigger).
- **Thiết kế Frosted Glass & Gold**: Giao diện cung trăng rực rỡ, thiệp mời trong suốt và phong cách hiện đại.
- **Form đăng ký nhận quà**: Check-in trực tuyến, sinh mã số may mắn và đồng bộ Google Apps Script / Google Sheets.
- **Nút Fanpage chính thức**: Popup chọn nhanh giữa 2 trang Fanpage chính thức: *Yamaha Town Nam Tiến* và *Nam Tiến Motor*.
- **Tương tác thú vị**: Nhặt bánh trung thu trúng quà bí mật, hiệu ứng âm thanh Synthesizer & Web Audio API, hạt sao lung linh qua HTML5 Canvas.
- **Responsive toàn diện**: Tối ưu hiển thị chuẩn xác trên cả màn hình Desktop và Mobile.

## 🚀 Cài đặt & Chạy thử nghiệm
Dự án được viết hoàn toàn bằng HTML5, CSS3, JavaScript thuần và GSAP 3 (không phụ thuộc framework nặng hay build tool).
Bạn chỉ cần mở trực tiếp file `index.html` trong trình duyệt hoặc đưa lên bất kỳ static hosting nào như **GitHub Pages**, **Vercel**, **Netlify**.
